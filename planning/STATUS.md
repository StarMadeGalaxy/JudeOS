## Проверки и ограничения

- `npm run check` в api: OpenAPI 3.0.3/$ref/operationId, bundled spec, соответствие реестру, 29 позитивных/негативных схемных fixtures и все примеры ответов, генерация TS и компиляция типизированного openapi-fetch клиента — пройдено. Раздельные варианты Attendance version 0/≥1 проверены fixtures; ложное предупреждение Redocly об их пересечении исключено только для этой схемы с пояснением.
- `JUDEOS_CHROMIUM_PATH=/usr/bin/chromium npm run check:swagger`: Playwright проверил семь операций, схемы/примеры команды и конфликта, отсутствие ошибок JS/Swagger; screenshot просмотрен. Браузер — системный Chromium 151.0.7922.173. Загрузка браузера с cdn.playwright.dev отклонена сетевой политикой (403 Domain forbidden); использован существующий браузер, ограничения не обходились.
- Runtime chi.Walk/HTTP/cookie/CSRF, RLS/FK, конкуренция и отзыв не проверялись: соответствующей реализации ещё нет. Схемные примеры не заменяют эти проверки. Синтетические данные; production-политики хранения/реальные сведения не вводятся.
- GitHub REST чтения Issue/аккаунта/коллабораторов и коннектор записи доступны. Project #1 через GraphQL возвращает Resource not accessible by integration; его состав/статусы/автоматизации и milestones/native dependencies не заявляются настроенными. Текущий assignee #16 подтверждён как NikishGum; Project In progress/Review не установлен и не подтверждён. Начало этой задачи и её claim предшествовали получению нового правила PR #77; уже подготовленный результат сохранён в PR, новая предметная работа не начинается.
