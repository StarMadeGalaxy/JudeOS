# Планирование JudeOS / Judo Pride

Актуализировано 7 октября 2026 года по итогам критического пересмотра. Рабочие документы согласованы с архитектурой 0.4 и планом MVP 1.1. Приложение ещё не реализовано; планы и схемы не являются доказательством работоспособности.

## Читать для начала разработки

1. [План MVP 1.1](MVP-DEVELOPMENT-PLAN.md) — границы, срезы S0–S5, приёмка и соответствие прежним P00–P12.
2. [Архитектура 0.4](ARCHITECTURE.md) — модульный монолит, модель, права, офлайн, восстановление и развитие.
3. [Следующие шаги](NEXT-STEPS.md) — краткий маршрут и конкретный старт S0/S1.
4. [Текущее состояние](STATUS.md) — ветка/PR, выполненные проверки и передача коллеге.

## Детали и обоснования

- [Модель данных](DATA-MODEL.md) и [сценарии по ролям](APP-FLOWS.md) — согласованы с текущими границами MVP.
- [Инфраструктура](INFRASTRUCTURE.md) — варианты размещения, резервирование; ресурсы/цены остаются оценками.
- [Критический разбор](ARCHITECTURE-REVIEW.md) — выявленные риски и внесённые исправления.
- [Исследование спортивных CRM](CRM-RESEARCH.md) — Gymdesk, TeamUp, SportMember и Martialytics, первичные источники.
- [ADR 0001](adr/0001-mvp-foundation-and-slices.md) — фиксация текущего технического подхода и последствий.
- [Подтверждённые решения и происхождение](DECISIONS.md) — исторические D01–D25 и статус позднего baseline.
- [Разговор с владельцем](OWNER-INTERVIEW.md), [прежнее исследование](RESEARCH.md), [журнал действий](ACTIONS.md) — контекст с датами; не альтернативный план текущего MVP.
- [Исходные документы](archive/2026-10-07-inputs/README.md) — архив для сравнения, не действующая спецификация.

Точные первичные D26–D63, MVP-INTERVIEW и прежний упомянутый ADR не представлены; поля D54 и отчёты D61 требуют отдельной спецификации. Явно выписанные правила позднего приложенного плана сохранены в текущем MVP. Нумерация недоступных решений не заполнена догадками. При расхождении исторических материалов использовать текущие архитектуру/план и проверять происхождение предметного правила.

Сотрудники — первая версия. Полный MVP включает журнал, людей/семьи, допуск, поддержку и сверку, два события Telegram, офлайн текущего дня, конкретные импорты/отчёты и четыре зала. Узкий онлайн-пилот — промежуточная проверка. ЛК, чаты, нормативы/рейтинги, медицинские файлы и биллинг платформы добавляются позже.
