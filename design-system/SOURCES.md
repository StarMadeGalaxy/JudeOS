# Источники и границы извлечения

Проверено 6 октября 2026 года. Система описывает визуальные правила для нового проекта на основе публичного кода сайта. Это извлечение и нормализация, а не новый бренд и не точная копия измеренного рендера.

## Основные источники

- [Главная Judo Pride](https://judopride.by/) — HTML, структура разделов, классы, встроенные стили, адреса изображений, подключение Rubik.
- [Основной CSS, версия 18](https://judopride.by/css/app.css?ver=18) — цвета, размеры, компоненты, responsive-правила, движение.
- [Дополнительный CSS, версия 9](https://judopride.by/css/app2.css?ver=9) — active-навигация, горизонтальная прокрутка, квадратный photoblock.
- [Bootstrap 5.3.3, подключённый сайтом](https://cdnjs.cloudflare.com/ajax/libs/bootstrap/5.3.3/css/bootstrap.min.css) — внешняя зависимость сетки и базовых элементов; отдельная копия не сохранялась.
- [Rubik: подключение, найденное в HTML](https://fonts.googleapis.com/css2?family=Rubik:wght@300;400;500;600;700;800;900&display=swap) — запрашиваемые веса и семейство. Временные файлы шрифтов использованы для визуальной памятки, в комплект не включены.

Публичные файлы собственных стилей сохранены в `reference/` для воспроизводимости. HTML целиком не сохранялся в проект: достаточно карты подтверждений ниже; служебные поля форм и скрипты аналитики в комплект не входят.

## Нормализация и дополнения

- `text` использует объявленный `--main-black`; фактический computed color обычного текста не измерен.
- `text-muted` выбран из существующего оттенка селектора города вместо малоконтрастных серых подписей.
- `link` затемнён с исходного `#3f74e8` до `#3468d4` для обычного текста на белом и основных серых подложках; исходный цвет на белом имеет контраст около 4.31:1.
- Близкие красные объединены в один основной токен; pill-радиусы объединены в 999 px.
- Для будущего проекта основной мобильный текст сохраняется 16 px; значимые мелкие метки увеличиваются до 12–13 px.
- Интервалы некоторых заголовков, внешние поля 16 px, минимальные области нажатия, focus, loading, состояния формы и reduced-motion являются дополнениями.
- В исходном CSS есть ошибочное объявление `--color-text-dark`: пропущена точка с запятой перед `--color-text-light`. Его значение не переносится в новую систему.
- Глобальное отключение outline и случайный `--primary-color: #ff3c78` не включены в нормативную основу.

## Что осталось проверить визуально

Доступ к браузеру отклонён инструментом из-за невозможности проверить административную политику, в том числе после ручного открытия пользователем страницы. Поэтому не подтверждены: видимые размеры и переносы в конечном рендере, загрузка Rubik в браузере, раскрытые меню, карусели, форма после отправки и mobile screenshots.

`overview.png` — самостоятельно собранная визуальная памятка по извлечённым токенам. Это не скриншот judopride.by и не утверждённый макет новой страницы.
