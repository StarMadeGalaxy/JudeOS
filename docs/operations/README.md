- [Диагностика и копии](runbook.md): health/readiness, время ответа, диск, проверка восстановления.

Проверенная локальная конфигурация не подтверждает существование публичного test. Площадка, домен/DNS, защищённый доступ управления и владелец эксплуатации ещё нужны. Проверки повторяются на этом baseline; будущие изменения интерфейсов требуют повторной проверки.
